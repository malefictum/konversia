# Конверсия (ремастер)

Экономическая настольная игра в браузере, по мотивам советской настольной игры «Конверсия» (около 1990 года).
Добывайте сырьё, стройте заводы, возите товар на континенты. Игра с ботами и по сети; две версии правил —
классика и «Конверсія · 1993». Вся графика нарисована заново.
